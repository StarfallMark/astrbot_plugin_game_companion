# 游戏伴侣

游戏伴侣让 Bot 与用户通过独立 WebUI 一起玩五子棋和中国象棋，同时保留 AstrBot 的正常聊天、人格、生活场景和长期记忆链路。

## 核心行为

- 用户通过自然语言邀请 Bot 玩五子棋或中国象棋，由 LLM 工具创建房间并切换游戏。
- 网页只负责棋盘、席位和关键局内回应；普通聊天继续在 QQ 中进行。
- Bot 根据人格选择简单、普通或困难棋力，玩家不能在网页直接选择难度。
- 五子棋可选玩家先手、Bot 先手或随机；象棋可选执红、执黑或随机，始终由红方先行。
- Bot 走棋有轻微延迟。五子棋搜索在线程中执行，象棋通过单独的 Pikafish 进程串行计算，不阻塞 AstrBot 事件循环。
- 用户在 QQ 中自然提出“再来一局”时，Bot 直接在原房间重置棋盘，保留链接、玩家身份、访客序号和累计比分，不创建新房间。
- 五子棋与象棋分别累计比分。切换游戏保留房间链接、玩家、访客序号和权限；进行中的棋局必须明确确认放弃后才能切换。
- 悔棋、暂停、继续、认输、身份确认和抢占纠正必须从原 QQ 会话发起。
- 普通走棋不调用模型，只有开局、明显威胁或重要吃子、胜负和再来一局等关键节点触发人格化表达。
- 身份确认前不读取该用户的长期记忆或生活场景，也不写入共同经历。
- 房间结束时仅保存一条摘要，不保存逐步棋谱。
- AstrBot 或插件重载时销毁所有活动房间，不恢复未完成棋局。

## 房间权限

插件配置中的游戏管理员与 AstrBot 管理员相互独立。

- 群聊默认只允许游戏管理员创建房间。
- 管理员创建的房间中，所有访客先进入观众席并获得稳定序号。管理员在“游戏管理台”选择序号并绑定玩家 QQ 后才能开局。
- 开放普通成员创建群聊房间后，首位申请者可以进入玩家席。创建者可以在原 QQ 会话说明实际序号，由 Bot 工具重置棋局并纠正席位。
- 私聊房间采用普通房间规则。
- 管理台展示创建者、访客序号、席位和房间状态，不展示棋盘或棋谱。管理员可以切换房间游戏，但不能设置棋力。

## 中国象棋引擎

中国象棋使用 [Pikafish](https://github.com/official-pikafish/Pikafish) 提供合法着法校验、终局判断和 Bot 走棋。插件不会导入第三方象棋规则 Python 库；Pikafish 作为独立进程运行。引擎不可用时只影响象棋，五子棋仍可正常创建和游玩。

默认允许管理员从游戏管理台按需安装，但不会自动下载。安装流程会：

1. 从 Pikafish 官方 GitHub Releases 读取最新发行版。
2. 下载 `.7z` 资产并校验 GitHub 提供的 SHA-256。
3. 只提取当前平台需要的可执行文件、`pikafish.nnue` 和许可证文件。
4. 在插件数据目录中原子替换托管版本，并执行 UCI 启动检查。

下载最多允许 160 MiB。可通过 `xiangqi.download_proxy` 显式设置 HTTP 代理；留空时继承进程的 `HTTPS_PROXY` 或 `HTTP_PROXY`。也可以设置 `xiangqi.engine_path` 使用自行安装的二进制，此时 `pikafish.nnue` 必须位于可执行文件同目录。

自动安装支持 Linux x86_64、Windows x86_64 和 macOS Apple Silicon；其他平台可以配置兼容的自备引擎。Pikafish 使用 GPL-3.0，NNUE 文件具有单独许可；官方许可证会随托管安装保存在插件数据目录。插件通过 `py7zr` 解压官方发行包。

象棋服务端以 Pikafish 返回的合法着法为准，采用 ICCS 坐标保存内存棋谱。无合法着法的一方判负；三次重复局面或连续 120 个半回合无吃子时判和。房间销毁或插件重载后不保存棋谱。

## 外部访问

房间服务默认按需监听 `127.0.0.1:6331`。如果端口已被占用，只会尝试后续十个端口，不会关闭或复用其他服务。

推荐二选一：

1. 在 `server.public_base_url` 配置现有 HTTPS 反向代理地址。
2. 安装 `cloudflared`，保留 `server.auto_quick_tunnel=true`，创建首个房间时按需生成 `trycloudflare.com` 临时 HTTPS 地址。

插件不会自动下载 `cloudflared`、修改防火墙、执行 UPnP 或退回到公开服务器 IP。

Quick Tunnel 首次启动后会保持到插件卸载或管理员在管理台手动停止，房间超时销毁不会让旧链接直接变成 Cloudflare 1033。已销毁房间的关闭原因只在内存中短期保留，旧链接会显示房间已经结束或过期。存在活动房间时如果 `cloudflared` 意外退出，插件会按间隔自动重建通道，并在原 QQ 会话发送新链接；临时域名发生变化后，旧消息中的链接无法继续使用。

反向代理需要将完整 HTTP 路径转发至实际监听端口。固定外部地址必须使用 HTTPS。

## 配置默认值

| 配置 | 默认值 | 说明 |
|---|---:|---|
| 允许群聊创建 | 开启 | 总开关关闭后管理员也不能创建 |
| 允许私聊创建 | 开启 | 私聊总开关 |
| 非管理员群聊创建 | 关闭 | 开启后普通群成员可创建 |
| 全部群聊房间上限 | 1 | `0` 为无限制 |
| 全部私聊房间上限 | 1 | `0` 为无限制 |
| 玩家席无人超时 | 60 秒 | `0` 关闭该项自动销毁 |
| 无有效操作超时 | 300 秒 | `0` 关闭该项自动销毁 |
| 允许管理台下载 Pikafish | 开启 | 可完全关闭托管下载 |
| 首次象棋房间自动下载 | 关闭 | 推荐在管理台确认后安装 |

页面刷新、观众进出和状态轮询不算有效操作。

本局结束后，玩家关闭页面会发送离开通知；若 8 秒内没有重新进入，房间会提前销毁并释放名额。刷新或短暂页面切换可以在宽限期内恢复。浏览器未能发送离开通知时，玩家心跳中断 60 秒后兜底销毁。进行中或暂停中的棋局不使用这项快速销毁，仍按“无有效操作超时”处理。

## 开发验证

```bash
pytest -q
ruff check .
node --check web/app.js
node --check pages/游戏管理台/manager.js
```

开发目标版本为 AstrBot `4.26.8`，Python `3.12+`。插件版本为 `0.1.1`。
